# Sentinel Nudge

Extension navigateur open-source de cyber-hygiene comportementale.

Sentinel Nudge observe les habitudes de navigation en local et produit des micro-nudges contextuels pour ameliorer la securite des utilisateurs, en s'appuyant sur les mecanismes valides par la recherche en sciences comportementales.

## Principes

- **Privacy by design** : tout traitement local, aucune telemetrie, aucun appel reseau sortant
- **Open source** : code auditable
- **Manifest V3** : permissions minimales, declaratives
- **Evidence-based** : chaque nudge s'appuie sur la litterature scientifique

## Statut

Projet en phase d'analyse (P1).
