Modules actifs

Activez ou désactivez chaque module. Vos données restent sur votre appareil.

M2Sites suspects

Analyse les domaines contre une liste locale de typosquatting. Aucune donnée transmise.

M3Navigateur

Vérifie la version de Chrome et avertit si une mise à jour critique est disponible.

M5Extensions tierces

Signale les extensions au comportement inhabituel (permissions excessives).

M7Mot de passe réutilisé

Toast M17 — Presse-papiers

M17Presse-papiers actif

Du contenu est dans votre presse-papiers depuis 8 minutes. Pensez à le vider si vous ne l'utilisez plus.

Overlay M9 — Passphrase

Conseil sécurité
M9 Passphrase

Ce formulaire accepte les longues phrases de passe. Une passphrase de 5 mots est bien plus sûre qu'un mot de passe complexe court.
