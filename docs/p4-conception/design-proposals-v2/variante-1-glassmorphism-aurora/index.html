3. Options / Paramètres

Paramètres

Consentements, quotas et confidentialité

Consentements par module

Chaque module peut être activé ou désactivé indépendamment. Vos données restent sur votre appareil.

M2 — Détection de sites suspects

Analyse les domaines visités contre une liste locale de typosquatting. Aucune donnée envoyée.

M3 — Mise à jour navigateur

Vérifie la version de Chrome et vous avertit si une mise à jour critique est disponible.

M5 — Extensions tierces

Signale les extensions au comportement inhabituel (accès données, permissions excessives).

M7 — Réutilisation de mots de passe

Détecte les mots de passe similaires entre sites. Traitement 100% local par hash AES-256.

M17 — Surveillance presse-papiers

Avertit si des données sensibles restent dans le presse-papiers plus de 5 minutes.

4. Toasts et overlays

Toast M7 — Réutilisation de mot de passe

Mot de passe déjà utilisé
Ce mot de passe ressemble à celui d'un autre site. Créer un mot de passe unique réduit votre risque en cas de fuite.

Toast M17 — Presse-papiers

Données dans le presse-papiers
Du contenu est dans votre presse-papiers depuis 8 minutes. Pensez à le vider si vous ne l'utilisez plus.

Overlay M9 — Passphrase (site identifié à risque)

Conseil sécurité

Ce formulaire de connexion accepte les passphrases longues. Une passphrase de 5 mots est 10× plus difficile à deviner qu'un mot de passe de 8 caractères complexes.

5. Onboarding — Écran d'accueil

Bienvenue dans Sentinel Nudge

Votre gardien discret de cyber-hygiène. Des micro-rappels contextuels pour construire de bonnes habitudes numériques, sans surveillance.

100% local. Aucune donnée ne quitte votre appareil. Pas de compte, pas de télémétrie. Licence libre GPL v3.

Module M7

Détection de réutilisation de mots de passe

Ce module détecte si vous utilisez le même mot de passe sur plusieurs sites. Le traitement est entièrement local (hachage AES-256 en mémoire, non persisté). Aucun mot de passe n'est stocké ni transmis.
