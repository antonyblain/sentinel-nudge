3. Options / Paramètres

Modules actifs

Activez ou désactivez chaque module indépendamment. Vos préférences sont stockées localement.

M2 Détection de sites suspects

Analyse les domaines visités contre une liste locale de typosquatting. Aucune donnée transmise.

M3 Mise à jour navigateur

Vérifie la version de Chrome et avertit si une mise à jour critique est disponible.

M5 Extensions tierces

Signale les extensions au comportement inhabituel (permissions excessives, accès données).

M7 Réutilisation de mots de passe

Détecte les mots de passe similaires entre sites. Traitement 100% local, hachage AES-256.

M17 Surveillance presse-papiers

Avertit si des données sensibles restent dans le presse-papiers plus de 5 minutes.

Ce mot de passe ressemble à celui d'un autre site. Un mot de passe unique par site réduit votre exposition en cas de fuite de données.

Toast M17 — Presse-papiers

Données dans le presse-papiers
8 minutes de rétention

Du contenu est resté dans votre presse-papiers. Si vous n'en avez plus besoin, pensez à le vider pour protéger vos données.

Overlay M9 — Conseil passphrase

Conseil sécurité M9

Utilisez une passphrase

Ce formulaire accepte les longues phrases de passe. Une passphrase de 5 mots (ex : "soleil-vélo-nuage-livre-tasse") est bien plus sûre qu'un mot de passe complexe de 8 caractères.

5. Onboarding — Accueil

Bienvenue dans Sentinel Nudge

Des micro-rappels intelligents pour de meilleures habitudes numériques. Sans surveillance, sans données partagées.

Tout le traitement est 100% local sur votre appareil. Pas de compte, pas de télémétrie, pas de données partagées. Licence libre GPL v3.

Module M7

Détection de réutilisation de mots de passe

Ce module détecte si vous utilisez le même mot de passe sur plusieurs sites. Traitement entièrement local : hachage AES-256 en mémoire vive, non stocké. Aucun mot de passe n'est lisible ni transmis.
