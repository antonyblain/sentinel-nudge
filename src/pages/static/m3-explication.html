M3

Score de cyber-hygiène — comment est-il calculé

Sentinel Nudge — Documentation du module M3

Description du module

Le module M3 calcule chaque lundi matin un score global de cyber-hygiène sur 100 points. Ce score synthétise votre comportement de sécurité numérique au cours de la semaine écoulée, mesuré par les autres modules actifs de Sentinel Nudge.

Le score est affiché sur le badge de l'extension et dans le tableau de bord. Il est conçu pour être compréhensible, actionnable et non culpabilisant.

Mécanisme de calcul

Le score est composé de cinq composantes pondérées :

Pondérations des composantes du score M3
Composante Module source Poids
Mise à jour navigateur M5 20 %
Résistance au phishing M6 25 %
Évitement de sites risqués M2 20 %
Diversité des mots de passe M7 20 %
Force des mots de passe M9 15 %

Si un ou plusieurs modules sont désactivés, leurs poids sont redistribués proportionnellement entre les modules actifs, de sorte que le total reste toujours 100 %.

Le calcul est réalisé localement par le service worker le lundi à 9h. Aucune donnée ne quitte votre navigateur.

Conseils pratiques

Pour améliorer votre score :
  • Maintenez votre navigateur à jour (impact fort : +20 points).
  • Complétez les quiz phishing M6 régulièrement (impact fort : +25 points).
  • Créez des mots de passe forts et uniques pour chaque site.
  • Activez tous les modules pour bénéficier d'une mesure complète.

Le score est disponible dans le tableau de bord avec l'historique des 52 dernières semaines et le détail de chaque composante.
