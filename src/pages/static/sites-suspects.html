Sentinel Nudge — Détecteur de sites suspects

Description du risque

Ce module surveille les conditions dans lesquelles vous saisissez un mot de passe. Certaines caractéristiques de domaine ou de connexion constituent des signaux d'alerte fortement corrélés aux attaques de phishing et d'usurpation d'identité.

Ces attaques visent à vous faire révéler vos identifiants sur un faux site qui imite un site légitime. Les dommages peuvent être immédiats : compromission de compte, vol de données bancaires, usurpation d'identité.

Mécanisme du module

Le détecteur analyse silencieusement quatre signaux au moment où vous cliquez sur un champ mot de passe :

  1. HTTP non chiffré — Un site de connexion qui n'utilise pas HTTPS transmet votre mot de passe en clair sur le réseau. Toute personne sur le même réseau (Wi-Fi public, routeur compromis) peut l'intercepter.
  2. Absence de HSTS preload — Les sites légitimes majeurs s'inscrivent dans la liste HSTS preload pour forcer HTTPS même avant la première visite. L'absence de cette inscription sur un domaine prétendant être un service connu est suspecte.
  3. Typosquatting (distance de Levenshtein) — Le domaine visité est comparé à une liste de domaines légitimes populaires. Si la distance d'édition est très faible (1 à 2 caractères), il peut s'agir d'un faux domaine délibérément similaire (ex. : paypa1.com, microsofft.com).
  4. Certificat TLS invalide — Un certificat expiré, auto-signé ou émis pour un autre domaine indique que la connexion n'est pas authentifiée.

Deux signaux ou plus déclenchent l'overlay. Un seul signal reste en observation silencieuse pour éviter les faux positifs.

Conseils pratiques

Actions recommandées quand l'alerte s'affiche :
  • Vérifiez l'URL dans la barre d'adresse : chaque caractère compte.
  • Vérifiez le cadenas HTTPS et l'identité du certificat.
  • Accédez au site directement depuis vos favoris ou en tapant l'URL complète.
  • En cas de doute, n'entrez jamais votre mot de passe et fermez l'onglet.

Si vous connaissez ce domaine et lui faites confiance, vous pouvez cliquer "Marquer comme de confiance" pour ne plus recevoir d'alerte pour ce domaine.
