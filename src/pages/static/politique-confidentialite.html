Confidentialité

Politique de confidentialité

Sentinel Nudge — Conforme RGPD Art. 13/14 — Dernière mise à jour : avril 2026

Qui sommes-nous ?

Sentinel Nudge ne collecte aucune donnée.

Tout ce qui est décrit dans ce document reste sur votre ordinateur. Aucune information ne nous parvient.

Sentinel Nudge est une extension de navigateur open-source publiée sous licence GPL v3. Son code source est librement consultable.

Contrairement à la plupart des extensions, Sentinel Nudge n'a pas d'éditeur central qui reçoit vos données. Vous êtes votre propre responsable de traitement. Toutes les données générées par l'extension restent stockées localement dans votre navigateur.

Quelles données sont traitées ?

Sentinel Nudge traite les catégories de données suivantes, toutes stockées uniquement sur votre appareil :

Donnée Forme stockée Ce qui n'est jamais stocké
Mots de passe vérifiés Empreinte SHA-256 salée Le mot de passe lui-même
Domaines visités Empreinte SHA-256 salée L'URL complète ou le nom de domaine en clair
Événements de nudge Type, date, action choisie Contenu des pages visitées
Scores de cyber-hygiène Valeur numérique hebdomadaire —
Résultats de quiz Score, catégories, date —
Configuration et préférences Paramètres de l'extension —

Où sont stockées les données ?

100% local — aucune donnée ne quitte votre ordinateur.

Sentinel Nudge n'effectue aucun appel réseau sortant. Il n'y a aucun serveur distant, aucun cookie, aucun identifiant de suivi.

Les données sont stockées dans deux emplacements locaux de votre navigateur :

  • IndexedDB : données structurées (événements, résultats de quiz, historique de scores).
  • chrome.storage.local : configuration, préférences et liste blanche de domaines.

Ces données ne sont accessibles qu'à l'extension Sentinel Nudge. Elles disparaissent si vous désinstallez l'extension ou videz les données de votre navigateur.

Combien de temps les données sont-elles conservées ?

Catégorie Durée de conservation Purge
Événements de nudge et empreintes de domaines 90 jours Automatique
Scores de cyber-hygiène hebdomadaires 52 semaines (1 an) Automatique
Résultats de quiz phishing 52 semaines (1 an) Automatique
Liste blanche de domaines Jusqu'à suppression manuelle Manuelle (page paramètres)
Configuration et préférences Jusqu'à désinstallation À la désinstallation

La purge automatique s'effectue en arrière-plan selon les délais ci-dessus. Vous pouvez aussi effacer toutes les données à tout moment depuis la page Paramètres.

Comment les données sont-elles protégées ?

  • Chiffrement AES-256-GCM : les données sensibles stockées localement sont chiffrées avec un algorithme de référence industrielle.
  • Hachage salé SHA-256 : les mots de passe et domaines ne sont jamais stockés en clair. Seule une empreinte irréversible est conservée.
  • Aucune transmission réseau : la permission réseau de l'extension est restreinte à la vérification des mises à jour du navigateur. Aucun autre appel sortant n'est effectué.

Vos droits (RGPD)

Comme vous êtes votre propre responsable de traitement, vous exercez vos droits directement depuis l'interface de l'extension :

  • Droit d'effacement (Art. 17) Effacez toutes vos données en un clic depuis la page Paramètres > Supprimer toutes les données.
  • Droit à la portabilité (Art. 20) Exportez l'ensemble de vos données au format JSON depuis Paramètres > Exporter mes données.
  • Droit de limitation (Art. 18) Désactivez chaque module indépendamment depuis la page Paramètres. Un module désactivé cesse tout traitement.
  • Droit d'accès (Art. 15) L'export JSON vous donne un accès complet et lisible à toutes les données stockées.

Module M7 — Gestionnaire de mots de passe

Le module M7 détecte les saisies de mots de passe en clair dans le presse-papiers. Ce traitement est soumis à un consentement explicite demandé lors de l'installation.

Vous pouvez retirer ce consentement et désactiver le module M7 à tout moment depuis la page Paramètres. La désactivation est immédiate et aucune donnée relative à ce module n'est conservée après désactivation.

Aucune télémétrie

Zéro appel réseau sortant. Zéro cookie. Zéro identifiant.

Sentinel Nudge ne participe à aucune forme de collecte de données, même anonymisée. Il n'y a pas d'analytique, pas de rapport d'erreur automatique, pas de mise à jour du corpus de questions par le réseau.

La seule communication réseau autorisée est la vérification de mise à jour du navigateur via l'API native chrome.runtime.requestUpdateCheck(), qui est une API système standard du navigateur et non un appel vers nos serveurs.

Signaler un problème

Sentinel Nudge est un projet open-source. Si vous identifiez un problème lié à la confidentialité ou à la sécurité, vous pouvez le signaler directement sur le dépôt GitHub du projet :

github.com/antonyblain/sentinel-nudge/issues

Pour les signalements de sécurité sensibles, privilégiez la fonctionnalité Security Advisories de GitHub (onglet Security du dépôt) afin de permettre une divulgation responsable avant publication publique.
