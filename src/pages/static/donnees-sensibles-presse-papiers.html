Données sensibles — risques du copier-coller

Sentinel Nudge — Détecteur de données sensibles dans le presse-papiers

Description du risque

Le presse-papiers (clipboard) est une zone mémoire partagée entre toutes les applications ouvertes sur votre ordinateur. Lorsque vous copiez un numéro de carte bancaire, un IBAN ou une clé API, cette donnée reste accessible à n'importe quelle application jusqu'à ce que vous copiez autre chose.

Des logiciels malveillants dits "clipboard stealers" surveillent en permanence le contenu du presse-papiers pour voler les données sensibles qui y transitent. Certains remplacent même les adresses de portefeuilles crypto copiées par les leurs.

Par ailleurs, coller une donnée sensible dans le mauvais champ — par exemple dans un champ de recherche ou un chat — peut exposer ces informations involontairement.

Mécanisme du module

Ce module surveille les événements paste sur les formulaires web. Lorsqu'une donnée collée correspond à l'un des patterns suivants, une alerte s'affiche :

  • Numéro de carte bancaire — Format 13 à 19 chiffres avec validation Luhn.
  • IBAN — Format international de compte bancaire (jusqu'à 34 caractères).
  • Clé API — Patterns typiques de tokens (longueur, entropie, préfixes courants).

La valeur détectée n'est jamais stockée ni transmise — seul le type de donnée est utilisé pour l'affichage de l'alerte. L'extension propose de vider immédiatement le presse-papiers via l'API navigator.clipboard.writeText('').

Conseils pratiques

Bonnes pratiques pour les données sensibles :

  • Videz votre presse-papiers immédiatement après avoir collé une donnée sensible.
  • N'utilisez pas le copier-coller pour des données bancaires sur des réseaux Wi-Fi publics.
  • Méfiez-vous des sites qui vous demandent de coller votre numéro de carte dans un chat ou un email.
  • Utilisez un gestionnaire de mots de passe qui efface le presse-papiers automatiquement après 30 secondes.
  • Sur Windows : Win + V permet de consulter et vider l'historique du presse-papiers.
