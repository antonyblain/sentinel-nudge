Mise à jour navigateur — pourquoi c'est important

Sentinel Nudge — Mise à jour navigateur

Description du risque

Votre navigateur est le logiciel le plus exposé aux menaces sur internet : il exécute du code provenant de millions de sites, gère vos mots de passe, vos sessions et vos paiements. Les failles de sécurité dans les navigateurs sont régulièrement découvertes et activement exploitées par des attaquants dans les jours qui suivent leur publication.

Une mise à jour de navigateur non installée est une fenêtre d'opportunité pour des attaques dites "0-day" ou "N-day" qui n'exigent pas d'interaction particulière de votre part : la simple visite d'une page malveillante peut suffire.

Mécanisme du module

Ce module utilise l'API native Chrome chrome.runtime.requestUpdateCheck() pour détecter si une mise à jour du navigateur est disponible. Cette vérification est effectuée toutes les 48 heures par une alarme en arrière-plan.

Conditions de déclenchement du rappel :

  • Une mise à jour est effectivement disponible.
  • 48 heures se sont écoulées depuis le dernier rappel.
  • Le navigateur n'est pas en mode plein écran (pour ne pas interrompre une présentation).
  • Le quota de nudges journalier n'est pas atteint.

Après 3 reports consécutifs ("Me rappeler dans 4 heures"), le bouton de report est masqué pour encourager l'action.

Conseils pratiques

Pour mettre à jour Chrome :
  • Cliquez sur les trois points en haut à droite → Aide → À propos de Google Chrome.
  • Chrome vérifie et installe automatiquement la mise à jour.
  • Relancez le navigateur pour appliquer la mise à jour.

Activez la mise à jour automatique dans les paramètres système pour ne jamais manquer une mise à jour critique. Sur Windows, Chrome se met à jour automatiquement via Google Update en arrière-plan.
